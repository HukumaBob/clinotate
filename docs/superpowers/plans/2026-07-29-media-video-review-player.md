# Video Review Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user return to an already-uploaded video, watch it in a real player, see previously-cut `Sequence`s as named segments on a timeline, mark a new start/end range and cut another `Sequence` from it without leaving the player — and, if the browser can't play the video's codec, detect that server-side and offer a one-click background transcode to H.264/MP4.

**Architecture:** Extend `Video` with codec-compatibility fields computed by `ffprobe` at upload time. Add a `VIDEO_TRANSCODE` job type reusing the existing generic `Job`/`JobRead` machinery, run by a **new, separate Celery worker process in `backend`** (CPU-only `ffmpeg`, must never compete with `ml-worker`'s GPU-bound SAM tasks or share its container). On the frontend, a new `VideoReviewPlayer` screen (reached by clicking a video row in the existing Media library table) replaces the two upload forms in place, showing a native `<video>` plus a custom timeline bar with existing `Sequence` segments, two mark buttons, and a compact creation form that reuses the same `useCreateSequenceFromVideo` mutation the existing `ExtractSequenceForm` already uses.

**Tech Stack:** FastAPI, SQLAlchemy, Pydantic, `subprocess`+`ffprobe`/`ffmpeg`, Celery+Redis, pytest — backend. React, TanStack Query, `openapi-fetch` generated client, Vitest + Testing Library, Playwright — frontend.

## Global Constraints

- **Language:** English only in all committed code, comments, docstrings, and UI copy — no Russian anywhere in the repo.
- **Object storage:** all binary media goes through `StorageService` (`backend/app/storage.py`) — never a direct filesystem path in domain code, except the already-sanctioned `tempfile.NamedTemporaryFile` pattern `media/service.py` already uses for OpenCV/ffmpeg/ffprobe calls that need a real path.
- **API contract:** REST + OpenAPI auto-generated by FastAPI; the frontend must use the regenerated typed `apiClient` (`frontend/src/shared/api/client.ts`) — never a hand-rolled untyped `fetch()`.
- **TDD:** every task below starts with a failing test.
- **UI theme:** dark only, Tailwind `class` dark-mode strategy — no light-background classes.
- Backend tests need the `endoscopy_test` database; a session-scoped autouse fixture (`backend/tests/conftest.py`, commit `e1ad521`) already isolates the full pytest session from the real `endoscopy` dev DB — no truncation workaround needed for this plan's tests.
- After any backend router/schema change, regenerate the OpenAPI contract before touching frontend code that depends on it: `cd backend && PYTHONPATH=. uv run python scripts/export_openapi.py`, then `cd frontend && npm run generate-api`.
- `backend` has no Dockerfile — it and its Celery worker(s) run directly on the host via `uv run`, per this repo's existing pattern (see `CLAUDE.md`'s "Running the stack"). Only `ml-worker` is containerized (it needs the GPU-enabled base image). The new transcode worker follows the same host-run pattern as the existing backend process, **not** a new Docker service.

```python
import json
import subprocess

# Browsers reliably play H.264 video in an MP4/MOV-family container.
# ffprobe reports this container family's format_name as this exact
# comma-joined string (confirmed empirically against a real ffprobe
# build, not assumed from documentation) -- verify against your ffprobe
# version if this check ever starts rejecting normal MP4 uploads.
_BROWSER_PLAYABLE_CONTAINERS = {"mov,mp4,m4a,3gp,3g2,mj2"}
_BROWSER_PLAYABLE_CODECS = {"h264"}


def probe_codec_compatibility(video_bytes: bytes) -> tuple[bool, str | None, str | None]:
    """Returns (browser_playable, container_format_name, video_codec_name).

    Runs real ffprobe against the file (not a guess from the filename
    extension) -- a `.mp4` file can still contain a codec (e.g. MPEG-4
    Part 2 / "mpeg4") no mainstream browser's <video> element will
    decode. Whitelist, not blacklist: an unrecognized/unparseable
    container or codec is treated as NOT playable, since a false "yes"
    here means a silent black-screen player with no path forward, while
    a false "no" only costs one avoidable transcode offer.
    """
    with tempfile.NamedTemporaryFile(suffix=".mp4") as tmp:
        tmp.write(video_bytes)
        tmp.flush()
        try:
            result = subprocess.run(
                [
                    "ffprobe",
                    "-v", "error",
                    "-select_streams", "v:0",
                    "-show_entries", "stream=codec_name",
                    "-show_entries", "format=format_name",
                    "-of", "json",
                    tmp.name,
                ],
                capture_output=True,
                text=True,
                timeout=30,
                check=True,
            )
        except (subprocess.CalledProcessError, subprocess.TimeoutExpired, FileNotFoundError):
            return False, None, None

    try:
        parsed = json.loads(result.stdout)
        container = parsed.get("format", {}).get("format_name")
        streams = parsed.get("streams", [])
        codec = streams[0].get("codec_name") if streams else None
    except (json.JSONDecodeError, IndexError, AttributeError):
        return False, None, None

    playable = container in _BROWSER_PLAYABLE_CONTAINERS and codec in _BROWSER_PLAYABLE_CODECS
    return playable, container, codec
```

```python
import subprocess
import tempfile
from datetime import datetime, timezone

from app.db import SessionLocal
from app.jobs.models import Job, JobStatus
from app.media.models import Video
from app.media.service import compute_checksum
from app.storage import get_storage_service
from app.worker.celery_app import celery_app


@celery_app.task(name="video_transcode")
def transcode_video(job_id: int) -> None:
    session = SessionLocal()
    storage = get_storage_service()

    job = session.get(Job, job_id)
    job.status = JobStatus.RUNNING
    job.started_at = datetime.now(timezone.utc)
    session.commit()

    try:
        video_id = job.payload["video_id"]
        video = session.get(Video, video_id)
        if video is None:
            raise ValueError(f"Video {video_id} not found")

        source_bytes = storage.download(video.storage_key)

        with tempfile.NamedTemporaryFile(suffix=".mp4") as source_tmp, \
             tempfile.NamedTemporaryFile(suffix=".mp4") as output_tmp:
            source_tmp.write(source_bytes)
            source_tmp.flush()

            subprocess.run(
                [
                    "ffmpeg", "-y",
                    "-i", source_tmp.name,
                    "-c:v", "libx264",
                    "-preset", "medium",
                    "-c:a", "aac",
                    "-movflags", "+faststart",
                    output_tmp.name,
                ],
                capture_output=True,
                check=True,
                timeout=600,
            )

            output_tmp.seek(0)
            output_bytes = output_tmp.read()

        new_checksum = compute_checksum(output_bytes)
        new_storage_key = f"videos/{new_checksum}.mp4"
        storage.upload(new_storage_key, output_bytes, content_type="video/mp4")

        video.storage_key = new_storage_key
        video.browser_playable = True
        video.container = "mov,mp4,m4a,3gp,3g2,mj2"
        video.video_codec = "h264"

        job.status = JobStatus.SUCCEEDED
        job.progress = 100
        job.result_ref = new_storage_key
        job.finished_at = datetime.now(timezone.utc)
        session.commit()
    except Exception as exc:
        session.rollback()
        job = session.get(Job, job_id)
        job.status = JobStatus.FAILED
        job.error = str(exc)
        job.finished_at = datetime.now(timezone.utc)
        session.commit()
    finally:
        session.close()
```

```ts
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";

import { apiClient } from "../shared/api/client";

export function useVideo(videoId: number | null) {
  return useQuery({
    queryKey: ["video", videoId],
    queryFn: async () => {
      const result = await apiClient.GET("/media/videos/{video_id}", {
        params: { path: { video_id: videoId as number } },
      });
      if (result.error) throw result.error;
      return result.data;
    },
    enabled: videoId !== null,
  });
}

export function useTranscodeVideo() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async (videoId: number) => {
      const result = await apiClient.POST("/media/videos/{video_id}/transcode", {
        params: { path: { video_id: videoId } },
      });
      if (result.error) throw result.error;
      return result.data;
    },
    onSuccess: (_data, videoId) => {
      queryClient.invalidateQueries({ queryKey: ["video", videoId] });
    },
  });
}
```

The `if (result.error) throw result.error;` guard is required — `openapi-fetch@0.17` never throws on a 4xx/5xx response, it always resolves `{ data, error }`; without this, TanStack Query's `onError` never fires. This exact pattern is already used throughout `useMediaLibrary.ts`/`useSequences.ts` — match it, don't reinvent it.

```tsx
import { useState } from "react";

import { useJob } from "../../entities/useJobs";
import { useTranscodeVideo } from "../../entities/useVideo";

export function TranscodePrompt({
  videoId,
  onTranscodeComplete,
}: {
  videoId: number;
  onTranscodeComplete: () => void;
}) {
  const [jobId, setJobId] = useState<number | null>(null);
  const transcode = useTranscodeVideo();
  const jobQuery = useJob(jobId);

  if (jobQuery.data?.status === "succeeded") {
    onTranscodeComplete();
  }

  function handleClick() {
    transcode.mutate(videoId, {
      onSuccess: (job) => {
        if (job) setJobId(job.id);
      },
    });
  }

  const status = jobQuery.data?.status;

  return (
    <div className="flex flex-col items-center gap-3 rounded border border-gray-800 bg-gray-900 p-8 text-center text-gray-300">
      <p>This video&apos;s format isn&apos;t supported by the browser player.</p>
      {status === "pending" || status === "running" ? (
        <p className="text-sm text-gray-400">Converting… {jobQuery.data?.progress ?? 0}%</p>
      ) : (
        <button
          type="button"
          onClick={handleClick}
          className="rounded bg-blue-600 px-4 py-2 font-medium text-white hover:bg-blue-500"
        >
          Convert video
        </button>
      )}
      {status === "failed" && (
        <p className="text-sm text-red-400">{jobQuery.data?.error}</p>
      )}
    </div>
  );
}
```

```tsx
const SEGMENT_COLORS = ["bg-blue-600", "bg-emerald-600", "bg-amber-600", "bg-purple-600", "bg-pink-600"];

type SequenceLike = {
  id: number;
  name: string;
  start_time: number;
  duration: number;
};

export function SequenceTimeline({
  durationSeconds,
  sequences,
  markStart,
  markEnd,
  onMarkStart,
  onMarkEnd,
  onOpenSequence,
  markStartDisabled,
  markEndDisabled,
}: {
  durationSeconds: number;
  sequences: SequenceLike[];
  markStart: number | null;
  markEnd: number | null;
  onMarkStart: () => void;
  onMarkEnd: () => void;
  onOpenSequence: (id: number) => void;
  markStartDisabled: boolean;
  markEndDisabled: boolean;
}) {
  function pct(seconds: number): number {
    if (durationSeconds <= 0) return 0;
    return (seconds / durationSeconds) * 100;
  }

  return (
    <div className="flex flex-col gap-2">
      <div className="relative h-10 w-full rounded bg-gray-800">
        {sequences.map((sequence, index) => (
          <div
            key={sequence.id}
            title={sequence.name}
            className={`absolute top-0 flex h-full items-center justify-center overflow-hidden whitespace-nowrap px-1 text-xs text-white ${SEGMENT_COLORS[sequence.id % SEGMENT_COLORS.length] ?? SEGMENT_COLORS[index % SEGMENT_COLORS.length]}`}
            style={{ left: `${pct(sequence.start_time)}%`, width: `${pct(sequence.duration)}%` }}
          >
            <span className="truncate">{sequence.name}</span>
            <button
              type="button"
              aria-label={`Open ${sequence.name}`}
              onClick={() => onOpenSequence(sequence.id)}
              className="ml-1 shrink-0 underline"
            >
              ↗
            </button>
          </div>
        ))}
        {markStart !== null && markEnd !== null && (
          <div
            data-testid="pending-mark-overlay"
            className="absolute top-0 h-full border-2 border-dashed border-yellow-400 bg-yellow-400/20"
            style={{
              left: `${pct(Math.min(markStart, markEnd))}%`,
              width: `${pct(Math.abs(markEnd - markStart))}%`,
            }}
          />
        )}
      </div>
      <div className="flex gap-3">
        <button
          type="button"
          onClick={onMarkStart}
          disabled={markStartDisabled}
          className="rounded border border-gray-700 px-3 py-1 text-sm hover:bg-gray-800 disabled:opacity-50"

          Mark start

        <button
          type="button"
          onClick={onMarkEnd}
          disabled={markEndDisabled}
          className="rounded border border-gray-700 px-3 py-1 text-sm hover:bg-gray-800 disabled:opacity-50"

          Mark end
        </button>
      </div>
    </div>
```

```tsx
import { useRef, useState } from "react";

import { useVideoSequences } from "../../entities/useSequences";
import { useVideo } from "../../entities/useVideo";
import { SequenceFromMarksForm } from "./SequenceFromMarksForm";
import { SequenceTimeline } from "./SequenceTimeline";
import { TranscodePrompt } from "./TranscodePrompt";

export function VideoReviewPlayer({
  videoId,
  onBack,
  onOpenSequence,
}: {
  videoId: number;
  onBack: () => void;
  onOpenSequence: (sequenceId: number) => void;
}) {
  const videoQuery = useVideo(videoId);
  const sequencesQuery = useVideoSequences(videoId);
  const videoRef = useRef<HTMLVideoElement>(null);
  const [markStart, setMarkStart] = useState<number | null>(null);
  const [markEnd, setMarkEnd] = useState<number | null>(null);
  const [videoReady, setVideoReady] = useState(false);

  function handleMarkStart() {
    if (videoRef.current) setMarkStart(videoRef.current.currentTime);
  }

  function handleMarkEnd() {
    if (videoRef.current) setMarkEnd(videoRef.current.currentTime);
  }

  function handleCreated() {
    setMarkStart(null);
    setMarkEnd(null);
    sequencesQuery.refetch();
  }

  const video = videoQuery.data;

  return (
    <div className="flex flex-col gap-4 rounded border border-gray-800 bg-gray-900 p-4">
      <div className="flex items-center justify-between">
        <h2 className="text-lg font-medium text-gray-100">{video?.title ?? "Video"}</h2>
        <button type="button" onClick={onBack} className="text-sm text-blue-400 hover:underline">
          ← Upload another video
        </button>
      </div>

      {video?.browser_playable === false ? (
        <TranscodePrompt videoId={videoId} onTranscodeComplete={() => videoQuery.refetch()} />
      ) : video ? (
        <>
          <video
            ref={videoRef}
            src={video.stream_url}
            controls
            className="w-full rounded bg-black"
            onLoadedMetadata={() => setVideoReady(true)}
          />
          <SequenceTimeline
            durationSeconds={video.duration_seconds}
            sequences={sequencesQuery.data ?? []}
            markStart={markStart}
            markEnd={markEnd}
            onMarkStart={handleMarkStart}
            onMarkEnd={handleMarkEnd}
            onOpenSequence={onOpenSequence}
            markStartDisabled={!videoReady}
            markEndDisabled={!videoReady}
          />
          {markStart !== null && markEnd !== null && markEnd !== markStart && (
            <SequenceFromMarksForm
              videoId={videoId}
              markStart={markStart}
              markEnd={markEnd}
              procedureId={video.procedure_id ?? undefined}
              onCreated={handleCreated}
            />
          )}
          {markStart !== null && markEnd !== null && markEnd === markStart && (
            <p className="text-sm text-red-400">Start and end can&apos;t be the same point.</p>
          )}
        </>
      ) : null}
    </div>
  );
}
```

`video.stream_url` is the presigned MinIO URL Task 3 already added to `VideoRead` — no further backend work needed in this task.
