# Media Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the real "Media" top-level screen (video upload → extract-sequence form with crop/fps, photo-batch upload, raw media library table with delete) per the design spec, replacing the current single-title video-upload placeholder.

**Architecture:** Extend the existing `app/media` FastAPI module (models, schemas, service, router) with sequence naming, crop-aware extraction, batch photo upload, a merged library listing endpoint, and delete endpoints — then rebuild `frontend/src/features/media` on top of the regenerated typed API client, replacing the old `VideoListPage`/`VideoUploadForm`/`FrameGrid` files entirely. Routing changes from `/videos` + `/videos/:videoId/sequences/:sequenceId` to `/media` + `/sequences/:sequenceId`.

**Tech Stack:** FastAPI, SQLAlchemy, Pydantic, OpenCV (`cv2`), pytest, TestClient — backend. React, TanStack Query, `openapi-fetch` generated client, Vitest + Testing Library, Playwright — frontend.

## Global Constraints

- **Language:** English only in all committed code, comments, docstrings, and UI copy — no Russian anywhere in the repo.
- **Object storage:** all binary media goes through `StorageService` (`backend/app/storage.py`) — never a direct filesystem path in domain code.
- **`taxonomy_version`:** not directly touched by this plan (Media doesn't reference `Label`), but don't introduce any new code path that reads/writes a `Label` without preserving this rule.
- **API contract:** REST + OpenAPI auto-generated by FastAPI; the frontend must use the regenerated typed `apiClient` (`frontend/src/shared/api/client.ts`) — never a hand-rolled untyped `fetch()`.
- **TDD:** every task below starts with a failing test.
- **UI theme:** dark only, Tailwind `class` dark-mode strategy — no light-background classes.
- Backend tests need the `endoscopy_test` database and hit the real dev DB via `TestClient` with fixed/timestamp-based data — if reruns cause unexpected 409s, truncate tables rather than assume a code defect (see `CLAUDE.md`).
- After any backend router/schema change, regenerate the OpenAPI contract before touching frontend code that depends on it: `cd backend && uv run python scripts/export_openapi.py`, then `cd frontend && npm run generate-api`.

```python
from datetime import date

from sqlalchemy import func
from sqlalchemy.orm import Session

from app.media.models import Sequence
from app.taxonomy.models import Procedure


def suggest_sequence_name(session: Session, procedure: Procedure, today: date) -> str:
    base = f"{procedure.name} {today.isoformat()}"
    existing_count = (
        session.query(func.count(Sequence.id))
        .filter(Sequence.name.like(f"{base}%"))
        .scalar()
        or 0
    )
    return f"{base} #{existing_count + 1}"
```

```python
from app.media.schemas import CropBox


def _apply_crop(frame, crop: "CropBox | None"):
    if crop is None:
        return frame
    height, width = frame.shape[:2]
    left_px = int(width * crop.left / 100)
    right_px = int(width * crop.right / 100)
    top_px = int(height * crop.top / 100)
    bottom_px = int(height * crop.bottom / 100)
    return frame[top_px : height - bottom_px, left_px : width - right_px]


def extract_frames(
    video_bytes: bytes, sample_fps: float = 1.0, crop: "CropBox | None" = None
) -> list[tuple[int, bytes, int, int]]:
    """Extracts frames at `sample_fps`, returns (frame_index, png_bytes, width, height)."""
    results: list[tuple[int, bytes, int, int]] = []
    with tempfile.NamedTemporaryFile(suffix=".mp4") as tmp:
        tmp.write(video_bytes)
        tmp.flush()
        capture = cv2.VideoCapture(tmp.name)
        source_fps = capture.get(cv2.CAP_PROP_FPS) or sample_fps
        step = max(int(round(source_fps / sample_fps)), 1)

        frame_index = 0
        source_frame_number = 0
        while True:
            success, frame = capture.read()
            if not success:
                break
            if source_frame_number % step == 0:
                frame = _apply_crop(frame, crop)
                height, width = frame.shape[:2]
                success_encode, buffer = cv2.imencode(".png", frame)
                if success_encode:
                    results.append((frame_index, buffer.tobytes(), width, height))
                    frame_index += 1
            source_frame_number += 1
        capture.release()
    return results
```

Note the `CropBox` import: `schemas.py` must not import back from `service.py` to avoid a circular import — `schemas.py` stays dependency-free (only `pydantic`), and `service.py` imports `CropBox` from it. Verify this direction before editing.

```python
@router.post("/sequences/photos", response_model=SequenceRead, status_code=status.HTTP_201_CREATED)
async def upload_photo_sequence(
    files: list[UploadFile],
    name: str = Form(...),
    procedure_id: int = Form(...),
    session: Session = Depends(get_session),
    storage: StorageService = Depends(get_storage_service),
) -> Sequence:
    procedure = session.get(Procedure, procedure_id)
    if procedure is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Procedure not found")

    decoded: list[tuple[bytes, int, int]] = []
    for upload in files:
        data = await upload.read()
        try:
            with Image.open(io.BytesIO(data)) as img:
                width, height = img.size
        except UnidentifiedImageError:
            raise HTTPException(
                status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
                detail=f"File '{upload.filename}' is not a valid image",
            )
        decoded.append((data, width, height))

    sequence = Sequence(video_id=None, procedure_id=procedure_id, name=name, start_time=0, duration=0)
    session.add(sequence)
    session.commit()
    session.refresh(sequence)

    for frame_index, (data, width, height) in enumerate(decoded):
        storage_key = f"frames/{sequence.id}/{frame_index}.png"
        storage.upload(storage_key, data, content_type="image/png")
        session.add(
            Frame(
                sequence_id=sequence.id,
                storage_key=storage_key,
                frame_index=frame_index,
                width=width,
                height=height,
                size_bytes=len(data),
            )
        )
    session.commit()
    return sequence
```

Note: validation happens for *all* files before any DB row is created, so a bad file anywhere in the batch means zero `Frame` rows are persisted — matches `test_upload_photo_batch_rejects_non_image_file`'s intent (no partial sequence left behind on failure).

This route must be declared before `/sequences/{sequence_id}` for the same path-ordering reason as Task 2's `suggest-name` — place it near `upload_standalone_frame` or immediately after `suggest_sequence_name`.

```python
from app.annotation.models import Annotation


@router.delete("/videos/{video_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_video(video_id: int, session: Session = Depends(get_session)) -> None:
    video = session.get(Video, video_id)
    if video is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Video not found")

    linked_count = session.query(Sequence).filter(Sequence.video_id == video_id).count()
    if linked_count > 0:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Delete or reassign this video's sequences before deleting it",
        )

    session.delete(video)
    session.commit()


@router.delete("/sequences/{sequence_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_sequence(sequence_id: int, session: Session = Depends(get_session)) -> None:
    sequence = session.get(Sequence, sequence_id)
    if sequence is None or sequence.video_id is not None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Sequence not found")

    has_annotations = (
        session.query(Annotation)
        .join(Frame, Annotation.frame_id == Frame.id)
        .filter(Frame.sequence_id == sequence_id)
        .first()
        is not None
    )
    if has_annotations:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="This sequence has annotated frames — remove annotations before deleting it",
        )

    session.query(Frame).filter(Frame.sequence_id == sequence_id).delete()
    session.delete(sequence)
    session.commit()
```

```tsx
import { useState } from "react";

import { useDeleteSequence, useDeleteVideo, useMediaLibrary } from "../../entities/useMediaLibrary";

function formatSize(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
}

export function MediaLibraryTable() {
  const libraryQuery = useMediaLibrary();
  const deleteVideo = useDeleteVideo();
  const deleteSequence = useDeleteSequence();
  const [confirmingId, setConfirmingId] = useState<number | null>(null);
  const [errorsById, setErrorsById] = useState<Record<number, string>>({});

  function handleDelete(id: number, kind: "video" | "photo") {
    const mutation = kind === "video" ? deleteVideo : deleteSequence;
    mutation.mutate(id, {
      onSuccess: () => {
        setConfirmingId(null);
        setErrorsById((errors) => ({ ...errors, [id]: "" }));
      },
      onError: (error: unknown) => {
        const detail = (error as { detail?: string } | undefined)?.detail ?? "Delete failed";
        setErrorsById((errors) => ({ ...errors, [id]: detail }));
      },
    });
  }

  return (
    <table className="w-full text-left text-sm text-gray-300">
      <thead>
        <tr className="border-b border-gray-800 text-gray-400">
          <th className="py-2">Filename</th>
          <th>Type</th>
          <th>Procedure</th>
          <th>Uploaded</th>
          <th>Size</th>
          <th>Sequences</th>
          <th />
        </tr>
      </thead>
      <tbody>
        {(libraryQuery.data ?? []).map((item) => (
          <tr key={`${item.kind}-${item.id}`} className="border-b border-gray-900">
            <td className="py-2">{item.filename}</td>
            <td>{item.kind}</td>
            <td>{item.procedure_id ?? "—"}</td>
            <td>{new Date(item.uploaded_at).toLocaleDateString()}</td>
            <td>{formatSize(item.size_bytes)}</td>
            <td>{item.linked_sequence_count}</td>
            <td>
              {confirmingId === item.id ? (
                <button
                  onClick={() => handleDelete(item.id, item.kind)}
                  className="rounded bg-red-600 px-2 py-1 text-white hover:bg-red-500"
                >
                  Confirm
                </button>
              ) : (
                <button
                  onClick={() => setConfirmingId(item.id)}
                  className="rounded border border-gray-700 px-2 py-1 hover:bg-gray-800"
                >
                  Delete
                </button>
              )}
              {errorsById[item.id] && (
                <p className="mt-1 text-xs text-red-400">{errorsById[item.id]}</p>
              )}
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

This test's `onError` path relies on Task 8's `useDeleteVideo`/`useDeleteSequence` already throwing `result.error` on a failed response — that fix is already part of the Task 8 implementation.
