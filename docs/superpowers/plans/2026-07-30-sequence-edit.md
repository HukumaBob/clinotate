# Sequence Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user rename/re-tag an existing `Sequence`, or re-cut its
start/end/fps (re-extracting frames, with an explicit confirmation
naming the annotations that will be deleted), from the video review
player's `SequenceTimeline`.

**Architecture:** A single `PATCH /media/sequences/{sequence_id}`
endpoint, dispatching on which fields are present: `name`/`procedure_id`
alone is a plain update; any of `start_time`/`duration`/`fps` triggers a
full re-cut (extract-then-delete ordering so a mid-operation failure
never leaves the sequence without frames). `SequenceRead` gains
`annotation_count` so the frontend can show an exact number before the
user confirms a re-cut. `SequenceTimeline` gains two new per-segment
actions wired to two new frontend components.

**Tech Stack:** FastAPI + SQLAlchemy + Pydantic (backend), React +
TanStack Query + Tailwind (frontend), pytest + vitest/testing-library
(tests).

class SequenceUpdate(BaseModel):
    name: str | None = None
    procedure_id: int | None = None
    start_time: int | None = None
    duration: int | None = None
    fps: float | None = None

    @model_validator(mode="after")
    def _check_temporal_fields_are_all_or_nothing(self) -> "SequenceUpdate":
        temporal = (self.start_time, self.duration, self.fps)
        provided = sum(1 for value in temporal if value is not None)
        if provided not in (0, 3):
            raise ValueError(
                "start_time, duration, and fps must all be provided together (a re-cut) "
                "or all omitted (a rename) — partial temporal updates are not allowed"
            )
        return self

```python
def recut_sequence(
    session: Session,
    storage: "StorageService",
    sequence: Sequence,
    video: Video,
    start_time: int,
    duration: int,
    fps: float,
) -> None:
    """Re-extracts a Sequence's frames with new start/end/fps.

    Extracts and uploads the new frames first, then deletes the old
    Frame rows (cascading to their Annotation rows) and updates the
    sequence's timing -- in that order, so a failure during extraction
    or upload leaves the sequence's existing frames and annotations
    untouched and the caller can simply retry.
    """
    video_bytes = storage.download(video.storage_key)
    trimmed = video_bytes  # extract_frames samples the whole clip at sample_fps;
    # start_time/duration windowing happens the same way create_sequence's caller
    # already relies on -- extract_frames has no start/duration params, so pass
    # the full video and let the existing frame_index numbering apply from 0.
    extracted = extract_frames(trimmed, sample_fps=fps)

    old_frame_ids = [
        frame_id
        for (frame_id,) in session.query(Frame.id).filter(Frame.sequence_id == sequence.id).all()
    ]

    new_frames = []
    for frame_index, png_bytes, width, height in extracted:
        storage_key = f"frames/{sequence.id}/{frame_index}-recut.png"
        storage.upload(storage_key, png_bytes, content_type="image/png")
        new_frames.append(
            Frame(
                sequence_id=sequence.id,
                storage_key=storage_key,
                frame_index=frame_index,
                width=width,
                height=height,
            )
        )

    if old_frame_ids:
        session.query(Annotation).filter(Annotation.frame_id.in_(old_frame_ids)).delete(
            synchronize_session=False
        )
        session.query(Frame).filter(Frame.id.in_(old_frame_ids)).delete(synchronize_session=False)

    for frame in new_frames:
        session.add(frame)

    sequence.start_time = start_time
    sequence.duration = duration
    session.commit()
```

**Important — read this before treating Step 3 as done:** the comment
above admits `extract_frames` has no `start_time`/`duration` windowing
parameter — it samples the *entire* video passed to it, exactly like
`create_sequence` already does (`router.py:191`, no trimming happens
there either; `start_time`/`duration` are stored on `Sequence` purely as
metadata about what range the frames conceptually represent, not as an
instruction to `extract_frames`). This matches existing behavior, so
`recut_sequence` is consistent with `create_sequence` — flag this to the
plan's reviewer/user if it looks wrong, since it means "start/end" in
this codebase today only labels a `Sequence`, it never actually trims
the source video before sampling. Do not silently add trimming logic in
this task — that would be a larger, out-of-scope behavior change to
`extract_frames` affecting `create_sequence` too.

Also note: `storage_key` uses a `-recut.png` suffix to avoid colliding
with any old frame's storage key of the same `frame_index` during the
brief window where both exist in MinIO simultaneously (extract-before-
delete means old and new keys coexist momentarily).

@router.patch("/sequences/{sequence_id}", response_model=SequenceRead)
def update_sequence(
    sequence_id: int,
    payload: SequenceUpdate,
    session: Session = Depends(get_session),
    storage: StorageService = Depends(get_storage_service),
) -> SequenceRead:
    sequence = session.get(Sequence, sequence_id)
    if sequence is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Sequence not found")

    is_recut = payload.start_time is not None
    if not is_recut:
        if payload.name is not None:
            sequence.name = payload.name
        if payload.procedure_id is not None:
            sequence.procedure_id = payload.procedure_id
        session.commit()
        return _sequence_read(sequence, session)

    if sequence.video_id is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="This sequence has no source video to re-cut from",
        )
    video = session.get(Video, sequence.video_id)
    if video is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Video not found")

    if payload.duration <= 0:
        raise HTTPException(
            status_code=status.HTTP_422_UNPROCESSABLE_ENTITY, detail="duration must be positive"
        )
    if payload.start_time + payload.duration > video.duration_seconds:
        raise HTTPException(
            status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
            detail="start_time + duration exceeds the video's duration",
        )

    if payload.name is not None:
        sequence.name = payload.name
    if payload.procedure_id is not None:
        sequence.procedure_id = payload.procedure_id

    recut_sequence(
        session, storage, sequence, video,
        start_time=payload.start_time, duration=payload.duration, fps=payload.fps,
    )
    return _sequence_read(sequence, session)
```

export function useUpdateSequence() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async (params: {
      sequenceId: number;
      name?: string;
      procedureId?: number;
      startTime?: number;
      duration?: number;
      fps?: number;
    }) => {
      const result = await apiClient.PATCH("/media/sequences/{sequence_id}", {
        params: { path: { sequence_id: params.sequenceId } },
        body: {
          name: params.name,
          procedure_id: params.procedureId,
          start_time: params.startTime,
          duration: params.duration,
          fps: params.fps,
        },
      });
      if (result.error) throw result.error;
      return result.data;
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ["sequences"] });
      queryClient.invalidateQueries({ queryKey: ["video-sequences"] });
      queryClient.invalidateQueries({ queryKey: ["media-library"] });
    },
  });
}

  sequence,
  markStart,
  markEnd,
  onDone,
}: {
  sequence: SequenceRead;
  markStart: number;
  markEnd: number;
  onDone: () => void;
}) {
  const [fps, setFps] = useState<number | "">("");
  const [confirming, setConfirming] = useState(false);
  const updateSequence = useUpdateSequence();

  const startTime = Math.round(Math.min(markStart, markEnd));
  const duration = Math.round(Math.abs(markEnd - markStart));

  function handleRecutClick(event: React.FormEvent) {
    event.preventDefault();
    setConfirming(true);
  }

  function handleConfirm() {
    if (fps === "") return;
    updateSequence.mutate(
      { sequenceId: sequence.id, startTime, duration, fps },
      { onSuccess: () => onDone() }
    );
  }

  return (
    <form onSubmit={handleRecutClick} className="flex flex-col gap-3 rounded border border-gray-800 bg-gray-900 p-4">
      <p className="text-sm text-gray-400">
        New range: {startTime}s – {startTime + duration}s ({duration}s)
      </p>
      <label className="flex w-24 flex-col gap-1 text-sm text-gray-300">
        FPS
        <input
          type="number"
          value={fps}
          onChange={(e) => setFps(e.target.value === "" ? "" : Number(e.target.value))}
          className="rounded border border-gray-700 bg-gray-800 px-3 py-2 text-gray-100"
          required
        />
      </label>
      {sequence.annotation_count > 0 && (
        <p className="text-sm text-red-400">
          This will delete {sequence.annotation_count} annotation{sequence.annotation_count === 1 ? "" : "s"} on this
          sequence&apos;s current frames.
        </p>
      )}
      {!confirming ? (
        <button
          type="submit"
          disabled={fps === ""}
          className="rounded bg-blue-600 px-3 py-2 font-medium text-white hover:bg-blue-500 disabled:opacity-50"
        >
          Re-cut
        </button>
      ) : (
        <div className="flex gap-2">
          <button
            type="button"
            onClick={handleConfirm}
            className="rounded bg-red-600 px-3 py-2 font-medium text-white hover:bg-red-500"
          >
            Confirm
          </button>
          <button
            type="button"
            onClick={() => setConfirming(false)}
            className="rounded border border-gray-700 px-3 py-2 text-sm hover:bg-gray-800"
          >
            Cancel
          </button>
        </div>
      )}
    </form>
  );
}
```
