# Frame "No Findings" Review Flag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an annotator explicitly mark a reviewed frame as "no findings" (no polyp/target object present), distinct from a frame nobody has looked at yet, so future YOLO training can use it as a trustworthy background image.

**Architecture:** Three new boolean/audit columns on `Frame`. Two new bulk endpoints (`bulk-mark-no-findings`, `bulk-clear-no-findings`) mirroring the existing `bulk-classify`/`bulk-clear-classification` pair in `app/annotation/router.py`. Every code path that inserts an `Annotation` row (2 in the main backend, 4 in ml-worker) resets the flag on its target frame in the same transaction. Frontend: a toolbar button in `SequenceGridToolbar` plus a badge on `FrameThumbnail`, following the existing Select-mode bulk-action pattern used by classification/quality/delete.

**Tech Stack:** FastAPI + SQLAlchemy + Alembic (backend), React + TanStack Query + Vitest (frontend), Celery worker (ml-worker) sharing the same Postgres DB via SQLAlchemy models duplicated in `ml-worker/app/models.py`.

**Spec:** [docs/specs/2026-08-14-frame-no-findings-flag-design.md](../../specs/2026-08-14-frame-no-findings-flag-design.md)

## Global Constraints

- No Russian in committed code/comments/docs — English only (CLAUDE.md).
- Dark theme only — any new UI classes must not introduce light-background classes.
- Never hand-edit `frontend/src/shared/api/generated/`; regenerate via `npm run generate-api` after backend schema changes, and regenerate `openapi.json` via `cd backend && PYTHONPATH=. uv run python scripts/export_openapi.py`.
- TDD: every backend and frontend-with-logic task gets a failing test before implementation.
- A frame cannot simultaneously have `no_findings_reviewed = true` and any `Annotation` row. Setting the flag on an already-annotated frame is a skip, not an override. Creating any annotation on an already-flagged frame silently clears the flag.
- `ml-worker/app/models.py` has its own independent copy of the `Frame` SQLAlchemy model (separate codebase, same DB/tables) — the new columns must be added there too, or ml-worker's queries/inserts against `frames` will break once the migration runs.
- There is unrelated in-progress uncommitted work on `backend/app/media/router.py`, `backend/app/media/schemas.py`, and `backend/tests/test_media.py` (a "Sequences list" screen) at plan-writing time. Tasks in this plan touch different functions in the same files (`FrameRead`, `_frame_read`) — check for conflicts with `git diff` before editing and merge cleanly rather than clobbering.

def create_classification_annotation(
    session: Session, frame_id: int, label_id: int, created_by: User
) -> Annotation:
    label = session.get(Label, label_id)
    if label is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Label not found")

    annotation = Annotation(
        frame_id=frame_id,
        label_id=label_id,
        taxonomy_version=label.taxonomy_version,
        annotation_type=AnnotationType.CLASSIFICATION,
        payload={},
        created_by_id=created_by.id,
    )
    session.add(annotation)

    frame = session.get(Frame, frame_id)
    if frame is not None and frame.no_findings_reviewed:
        frame.no_findings_reviewed = False
        frame.no_findings_reviewed_by_id = None
        frame.no_findings_reviewed_at = None

    session.commit()
    session.refresh(annotation)
    return annotation
```

export function useBulkMarkNoFindings(sequenceId: number) {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async ({ frameIds }: { frameIds: number[] }) => {
      const result = await apiClient.POST("/annotation/frames/bulk-mark-no-findings", {
        body: { frame_ids: frameIds },
      });
      return result.data;
    },
    onSuccess: (_data, variables) => {
      for (const frameId of variables.frameIds) {
        queryClient.invalidateQueries({ queryKey: ["annotations", frameId] });
      }
      queryClient.invalidateQueries({ queryKey: ["frames", sequenceId] });
    },
  });
}

export function useBulkClearNoFindings(sequenceId: number) {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async ({ frameIds }: { frameIds: number[] }) => {
      const result = await apiClient.POST("/annotation/frames/bulk-clear-no-findings", {
        body: { frame_ids: frameIds },
      });
      return result.data;
    },
    onSuccess: (_data, variables) => {
      queryClient.invalidateQueries({ queryKey: ["frames", sequenceId] });
    },
  });
}
```
